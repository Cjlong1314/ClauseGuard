# ClauseGuard合同智能审查系统——界面风格调研报告

版本：V1.0 | 调研日期：2026年10月 | 调研方式：实际访问Ant Design/TDesign/Vercel Geist官网+知名产品案例分析
项目背景：面向律所的B端合同审查系统，纯HTML+CSS+原生JS单页（无框架），现有品牌色#1f3a5f深蓝/#2e75b6蓝，浅灰工作台。

---

## 一、五大风格方向调研

### 1. 企业级设计系统风（代表：Ant Design / Arco Design）

**实测来源**：ant.design官方规范（v6.6.5），品牌蓝#1677FF，中性色采用透明度体系（一级文本#000000E0、二级#000000A6、布局背景#F5F5F5），功能色（成功/错误/警告/链接）语义明确；强调"企业级产品设计中的色彩应用是克制的"——色彩服务于信息传递与操作引导。

**核心视觉特征**：品牌蓝主色+灰色中性层、卡片化布局、4px栅格体系、组件密度中等、阴影克制（分层阴影）、无衬线字体。

- 优点：成熟稳定、B端认知成本最低、组件规范完整、色板生成算法可扩展
- 缺点：视觉同质化严重，"千站一面"，缺乏品牌记忆点
- **适配度评分：5/5**。B端法律审查工具的信息密度、表格、表单场景与其设计假设完全吻合。

### 2. 品牌蓝现代风（代表：TDesign腾讯蓝 / 飞书）

**实测来源**：tdesign.tencent.com/design/color。腾讯蓝#0052D9为主题色，功能色（错误#D54941/告警#E37318/成功#2BA471）均扩展10级HCT色阶保证亮度均等；亮点是"带品牌色倾向的中性色"——向灰阶中混入8%-12%品牌蓝（如BlueGray1 #F3F3F4），凸显品牌氛围；采用全局语义Token+组件Token双层体系。

**核心视觉特征**：主题蓝+蓝倾向中性色、语义Token、清爽分层的界面层级、数据可视化色板与UI统一。

- 优点：品牌感强于Ant Design、色阶科学（对比度均标注WCAG达标）、Token体系利于无框架项目手工维护
- 缺点：蓝#0052D9偏深艳，与现有#2e75b6品牌色需调和
- **适配度评分：4.5/5**。其"品牌倾向中性色+语义Token"思路特别适合ClauseGuard这种纯CSS无框架项目（变量即Token）。

### 3. 极简黑白工程风（代表：Vercel Geist / Linear）

**实测来源**：vercel.com/geist/colors。10级灰阶+Gray alpha透明度体系；核心是组件色角色化——Color1-3组件背景（默认/hover/active）、Color4-6边框（默认/hover/active）、Color7-8高对比背景、Color9-10文本图标；页面双背景色（Background1/2）做微妙层级。Linear同属此类：深色底、低饱和、细边框、强键盘效率感。

**核心视觉特征**：黑白灰主导、零彩色干扰、1px细边框、小圆角（6px）、极高信息密度、等宽字体点缀、暗色模式原生。

- 优点：极致克制专业、工程师审美、暗色模式友好
- 缺点：对律所用户偏"极客"，风险等级等语义信息需要彩色辅助，冷感强
- **适配度评分：3/5**。可借鉴其"色角色Token"与边框体系，但整体气质不符。

### 4. 轻协同办公风（代表：Notion / Teambition / 飞书文档）

**核心视觉特征**：白底大留白、弱边框（靠阴影和灰底分区）、大圆角（8-12px）、舒适行高、彩色图标点缀、强调内容而非容器。

- 优点：亲和、易上手、阅读舒适
- 缺点：数据密度低，表格/表单场景支持弱，"工具感"不足
- **适配度评分：3/5**。适合文档型产品，审查工作台的密度需求撑不起这种松弛感。

### 5. 金融专业风（代表：Stripe Dashboard / 法务SaaS类如LegalMate）

**核心视觉特征**：浅灰底(#F6F8FA)+白卡片、品牌紫/蓝低饱和强调色、数据可视化精致（细线条图表）、字体层级分明、状态色彩克制而准确、留白与密度平衡得当。

- 优点：专业信任感最强，与"法律+财务"场景气质契合，数据展示精致
- 缺点：需要较强设计功力把控细节，无框架下手工还原成本略高
- **适配度评分：4.5/5**。Stripe Dashboard被广泛认为是B端视觉天花板，其"信任感"正是律所工具最需要的气质。

## 二、2024-2025 B端/SaaS后台设计趋势

1. **浅色极简+低饱和强调色**：大面积中性浅底（#F6F8FA级），强调色低饱和化（Stripe紫#635BFF、TDesign腾讯蓝均为克制蓝紫系），彩色只用于语义和焦点。
2. **卡片化+大圆角**：容器卡片化（8-12px圆角）、阴影软化（低透明度大扩散），层级靠"背景色差+阴影"而非边框。
3. **语义Token体系**：色彩不再硬编码，而是`--brand-color`、`--bg-container`、`--text-primary`等语义变量（TDesign/Ant均如此），暗色模式与品牌换肤的基础。
4. **暗色模式**：主流SaaS标配，但B端生产力工具仍以浅色为主、暗色为可选。
5. **数据密度与留白平衡**：表格行高42-48px、分区靠留白与细分割线；高密度场景（审查列表）提供紧凑模式。
6. **微交互与空状态**：hover过渡0.15-0.2s、骨架屏、插画化空状态成为品质感标配。

## 三、候选方案（含设计令牌草案）

### 方案A：深蓝专业版（延续品牌，稳态升级）

保留现有深蓝品牌基因，用设计系统方法重做质感。气质对标Stripe Dashboard+Ant Design企业风。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 主色 | #1F3A5F | 顶栏/主按钮/标题 |
| 强调色 | #2E75B6 | 链接/选中/焦点 |
| 页面背景 | #F4F6FA | 全局底色 |
| 卡片背景 | #FFFFFF | 容器 |
| 卡片圆角 | 10px | 全局统一 |
| 阴影 | 0 2px 12px rgba(31,58,95,.08) | 卡片默认 |
| 边框 | #E3E9F0 | 分隔线/输入框 |
| 主文本 | #2C3E50 | 正文 |
| 次文本 | #8A97A8 | 辅助 |
| 功能色 | 成功#2BA471/错误#D54941/警告#E37318/信息#2E75B6 | 状态语义 |

**适合理由**：与现有代码和用户习惯零冲突，改造成本最低，风险可控；深蓝天然传递"法律"的严肃信任感。

### 方案B：品牌倾向中性版（TDesign思路移植）

向中性灰阶混入10%现有品牌蓝，形成"蓝灰"氛围中性色，界面更轻盈现代；主色提亮为#2E75B6，顶栏由深蓝实底改为白底+深蓝文字的浅色导航。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 主色 | #2E75B6 | 交互/选中 |
| 主色hover | #255A8E | 交互hover |
| 页面背景 | #F3F5F9（蓝倾向） | 全局底色 |
| 卡片背景 | #FFFFFF | 容器 |
| 蓝灰边框 | #DCDDE1 | 边框 |
| 蓝灰主文本 | #323843 | 正文 |
| 蓝灰次文本 | #535D6D | 辅助 |
| 卡片圆角 | 12px | 更现代 |
| 阴影 | 0 1px 3px rgba(46,117,182,.10) | 轻阴影 |

**适合理由**：视觉更轻盈现代，品牌倾向中性色（TDesign验证过的8%-12%混色法）让整体"蓝而不闷"；浅色导航是2024-2025主流趋势。

### 方案C：极简工程版（Vercel/Linear思路）

黑白灰+细边框+高密度，彩色仅风险等级语义。

**适合理由**：信息密度最高，但气质偏极客，与律所用户画像有距离。**适配度有限，仅作对照，不推荐。**

## 四、最终推荐：方案A与方案B融合——"深蓝品牌+蓝灰中性"专业版

**推荐理由**：

1. **保留深蓝顶栏**（#1F3A5F）作为品牌锚点——律所场景需要"庄重信任感"，这是纯浅色导航给不了的；同时顶栏是全页面唯一深色块，形成清晰的视觉锚。
2. **工作台采用方案B的蓝灰中性体系**：页面底#F3F5F9、卡片白底10-12px圆角、轻阴影、蓝灰文字层级——吸收TDesign实测验证的品牌倾向中性色，整体轻盈不沉闷。
3. **色彩克制原则**（Ant Design企业级准则）：界面80%为中性色，彩色只出现在风险等级（高#C0392B/中#E37318/低#2BA471）、主按钮、链接与焦点态。
4. **纯CSS语义Token落地**：无框架项目正好用CSS变量实现TDesign式语义Token（--bg-page/--bg-card/--text-primary/--brand/--radius/--shadow），一份变量即可全局换肤，也为未来暗色模式留好接口。
5. **改造成本可控**：所有改动静态作用于现有index.html的样式层，不动JS逻辑与接口，符合本期"纯前端风格升级"边界。

**落地要点摘要**（供实施子任务直接使用）：
- 顶栏：保持深蓝渐变+CG Logo，导航按钮hover用rgba(255,255,255,.12)
- 卡片：白底、10px圆角、阴影0 2px 12px rgba(31,58,95,.08)、hover阴影加深
- 表格：表头#EEF4FB蓝底粗体、行斑马纹#FAFBFD、hover行#F0F6FC、行高≥44px
- 按钮：primary #2E75B6/hover #255A8E；ghost描边；danger #C0392B描边
- 空状态：居中emoji图标+主副两行文案（--muted色）
- 微动效：全局transition .15-.2s、视图切换fadeUp .25s、细滚动条
